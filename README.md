# Панель управления поездками (Trips Dashboard)

Тестовое задание на верстку экрана из Figma. Проект представляет собой таблицу с данными о поездках, панелью фильтров и адаптивным интерфейсом.

## ✨ Особенности реализации

- **Адаптивная верстка**: На десктопе таблица отображается полностью, на мобильных устройствах появляется горизонтальный скролл, а фильтры перестраиваются в колонку.
- **Рендеринг данных**: Таблица генерируется динамически на основе массива объектов с помощью JavaScript (`map` + `join`).
- **UI/UX**: Настроены состояния наведения (hover) для строк таблицы, стилизованы статусы поездок (цветные бейджи), добавлены современные инпуты и кнопки.
- **Чистый код**: Убрано жесткое позиционирование (`margin-left: 20%`), используются `Flexbox` и `CSS Grid`.

## 🛠 Стек

- HTML5 (семантическая верстка, `<thead>`, `<tbody>`)
- CSS3 (Flexbox, адаптивность, тени, переменные)
- Vanilla JavaScript (динамический рендеринг DOM)

## 🚀 Запуск
Откройте файл `index.html` в браузере.
